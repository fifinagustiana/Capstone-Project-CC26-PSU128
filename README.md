# StuntingScan: Web Prediksi Risiko Stunting pada Balita Berbasis Deep Learning

**Capstone Project - CC26-PSU128**

---

## 📖 Tentang Proyek
StuntingScan adalah aplikasi berbasis *web* yang dirancang untuk memprediksi risiko *stunting* pada balita secara dini menggunakan model *Deep Learning*. Sistem ini diharapkan mampu membantu tenaga medis maupun orang tua dalam memantau tumbuh kembang dan status gizi anak, serta memberikan rekomendasi kesehatan otomatis yang ditenagai oleh teknologi *Generative AI*. Proyek ini merupakan bagian dari tugas akhir (Capstone) program Coding Camp 2026 powered by DBS Foundation.

- **ID Tim Capstone Project:** CC26-PSU128

- **Tema yang Dipilih:** Healthy Lives & Well-being
